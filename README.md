# AI 探索笔记

一些关于「让软件不需要动脑」的想法和试验记录。

## 我在想什么

- 好的 AI 不该要求使用者先学会一套规则
- 就像 FPS 游戏，玩着玩着就会了，而不是先读三十页说明书
- 目标是：把复杂度收进系统内部，把简单留给使用者

## 这个仓库放什么

- [ ] 想法草稿
- [ ] 试验记录，包括失败的尝试
- [ ] 读到的相关资料与摘录
